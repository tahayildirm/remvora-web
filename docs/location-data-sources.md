# Address data

Country codes: https://github.com/datasets/country-list (249 entries, Public Domain Dedication and License). Names are localized with browser Intl.DisplayNames.

Türkiye provinces/districts: https://github.com/ubeydeozdmr/turkiye-api ; fetched https://api.turkiyeapi.dev/v2/provinces and /v2/districts on 2026-09-18. Dataset includes 81 provinces and 973 districts. MIT notice distributed in public/turkiyeapi-LICENSE.txt. This independent dataset is bundled locally so selecting an address does not transmit user data to the source API. Other countries support country selection with manual region/district entry. Street address and postal code are not inferred from a province/district.
